# ETS2 Configurable Mirrors v0.2.0

Download and double-click the single Windows x64 `.exe` to customize ETS2’s left and right virtual mirrors. The executable is unsigned. `SHA256SUMS.txt` contains its expected SHA-256 checksum. If an earlier copy showed a PyInstaller embedded PKG archive error, download the replacement and verify its checksum.

## Highlights

- Apply the Compact preset used for the Compact Virtual Mirrors mod, or design your own layout with the live preview and exact numeric controls.
- Start editing immediately. Choose folders when needed in **Tools → Directories**.
- Use **Set Up HUD Files** for help finding ETS2, extracting the HUD with the official SCS tool, and checking the extracted files.
- Save a separate layout with **File → Save Config As**. Build the previewed layout, then install it or open the output folder. The editor requires a fresh build after layout or build settings changes.

The editor opens without ETS2. To build a mod, supply the extracted HUD files from the version of the game you use. Both the Compact mod and local editor builds replace the same virtual mirror HUD paths. Enable only one of them in Mod Manager.
